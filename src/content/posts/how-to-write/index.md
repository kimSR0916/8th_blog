이 블로그의 글은 Markdown 파일입니다. 파일을 추가해 PR을 올리고, `main`에 합쳐지면 배포됩니다.

## 처음 한 번만: 글쓴이 등록

`src/content/authors/` 아래에 JSON 파일을 만듭니다. 파일 이름이 글쓴이 id가 되므로 영문 소문자, 숫자, 하이픈으로 짓습니다.

```json
{
  "name": "이름",
  "role": "백엔드",
  "bio": "한 줄 소개",
  "github": "github-id"
}
```

`name`만 필수입니다. 나머지는 빼도 됩니다.

## 초안 만들기

아래 명령은 글 폴더와 기본 양식을 만듭니다. `my-first-post`는 글 주소가 되고, `team` 자리에는 글쓴이 id를 적습니다.

```bash
npm run new -- my-first-post team
```

생긴 `index.md`의 맨 위에는 글 정보가 있습니다.

| 항목 | 설명 |
| --- | --- |
| `title` | 글 제목 |
| `description` | 목록과 검색 결과에 보이는 설명, 200자 이내 |
| `date` | 발행일 |
| `updated` | 크게 고친 날짜, 없으면 생략 |
| `authors` | 글쓴이 id 목록, 여러 명 가능 |
| `tags` | 태그 목록 |
| `draft` | `true`면 배포되지 않음 |

필수 항목이 빠졌거나 등록되지 않은 글쓴이를 적으면 빌드가 멈추고 이유를 알려 줍니다.

## 본문 쓰기

제목은 `##`부터 씁니다. `##`와 `###`는 목차에 자동으로 들어갑니다.

### 이미지

글과 같은 폴더에 이미지를 두고 상대 경로로 넣습니다. 크기 최적화는 빌드할 때 처리합니다.

```md
![요청이 캐시를 거치는 순서](./cache-flow.png)
```

### 다른 글로 링크

이 블로그의 다른 글은 현재 글을 기준으로 한 상대 경로로 연결합니다.

```md
[글 쓰는 법](../how-to-write/)
```

## 미리 보기

```bash
npm run dev
```

터미널에 나온 주소를 열면 초안까지 볼 수 있습니다. 검색은 개발 서버에서 동작하지 않으므로, 확인하려면 `npm run build`와 `npm run preview`를 차례로 실행합니다.

## 발행하기

1. `draft: true`를 지웁니다.
2. 브랜치를 만들어 PR을 올립니다. 빌드 검사가 자동으로 돕니다.
3. 팀원의 리뷰를 받고 `main`에 합치면 배포됩니다.

> 올리기 전에 비밀 키, 내부 주소, 개인정보가 코드나 화면 캡처에 남아 있지 않은지 꼭 확인하세요. 저장소가 공개라면 초안 파일도 누구나 볼 수 있습니다.
