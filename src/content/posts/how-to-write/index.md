글은 웹 편집기에서 씁니다. 화면 위의 **글쓰기**를 누르면 열립니다. 저장한 글은 GitHub 저장소에 커밋되고, 잠시 뒤 블로그에 배포됩니다.

## 처음 한 번만: 로그인 준비

글을 읽는 데는 로그인이 필요 없습니다. 쓰거나 고칠 때만 GitHub 계정으로 로그인합니다.

1. 저장소 관리자에게 협업자로 초대해 달라고 요청하고, 초대를 수락합니다.
2. **글쓰기**를 누르거나 고칠 글에서 **이 글 수정**을 누릅니다.
3. **GitHub로 로그인** 버튼을 누르고 권한을 승인합니다.

한 번 로그인하면 그 브라우저에서 유지됩니다. 공용 컴퓨터에서는 쓰고 나서 로그아웃하세요.

## 글 쓰고 발행하기

1. **글** 목록에서 새 글을 만듭니다.
2. 제목, 설명, 글쓴이, 본문을 채웁니다. 본문에는 이미지, 코드, 표를 넣을 수 있습니다.
3. **초안**을 켠 채 저장하면 블로그에 나오지 않습니다.
4. 다 썼으면 **초안**을 끄고 저장합니다.

글 주소는 제목에서 만들어집니다. 짧은 영문 주소를 원하면 저장하기 전에 슬러그를 고치세요.

> 올리기 전에 비밀 키, 내부 주소, 개인정보가 코드나 화면 캡처에 남아 있지 않은지 꼭 확인하세요. 저장소가 공개라 초안도 GitHub에서는 보입니다.

## 글쓴이 등록

**글쓴이** 목록에 팀원이 등록돼 있습니다. 소개나 GitHub 아이디를 추가하려면 자기 항목을 열어 고치면 됩니다.

## 코드 편집기에서 쓰기

Markdown 파일을 직접 고쳐도 됩니다.

```bash
npm ci
npm run new -- my-first-post amy
npm run dev
```

`src/content/posts/my-first-post/index.md`가 생깁니다. `amy` 자리에는 `src/content/authors/`에 있는 파일 이름을 적습니다. 브랜치를 만들어 PR을 올리면 빌드 검사가 돌고, `main`에 합치면 배포됩니다.

개발 서버에서 **글쓰기**를 열면 로그인 없이 로컬 저장소 폴더를 골라 웹 편집기로 쓸 수도 있습니다. Chrome이나 Edge에서 됩니다.
