가고 싶은 카페나 팝업을 영상에서 보고 저장해 둡니다. 막상 시간이 생기면 어디에 저장했는지 찾기 어렵고, 찾아도 지금 상황에 맞는지 다시 따져 봐야 합니다.

KeepGo는 이 문제에서 출발했습니다. 저장한 정보를 방문 계획으로 잇기 어려워하는 20~30대가 주된 사용자이고, **저장만 해 둔 "가고 싶은 곳"을 실제로 떠나는 일정으로 바꾸는 것**이 목표입니다.

## 두 가지를 다르게 합니다

- 소셜미디어 콘텐츠를 AI가 장소와 이벤트로 자동 정리합니다.
- 정리에서 끝내지 않고, 빈 시간과 상황에 맞는 외출 코스까지 구성합니다.

## 영상이 코스가 되기까지

흐름은 크게 두 갈래입니다.

### 콘텐츠 수집

1. 유튜브 쇼츠를 수집합니다.
2. 영상을 분석해 장소 정보를 정해진 형식으로 정리합니다.
3. 실제로 있는 장소인지 검증하고 좌표를 찾습니다.
4. 결과를 MySQL 보관함에 저장하고, 장소 요약의 임베딩은 Chroma에 저장합니다.

### 챗봇 추천

1. 사용자의 말에서 날짜나 지역 같은 조건과 취향을 뽑습니다.
2. 지역을 좌표로 바꾸고 반경 안의 장소를 먼저 거릅니다.
3. 임베딩으로 후보를 압축하고 조건에 맞는지 판단합니다.
4. 코스를 조합하고 이동 시간과 도착 시각을 계산합니다.
